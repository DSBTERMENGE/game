# Fontes de dados

Esta pasta guarda os arquivos originais usados para importar resultados.

Regras:

- os arquivos-fonte são somente leitura para a aplicação;
- o importador nunca deve modificar ou sobrescrever o arquivo selecionado;
- uma planilha atualizada pode substituir a fonte de trabalho, mas a comparação
  com o banco deve inserir apenas novidades e apontar divergências;
- arquivos produzidos pelo sistema, relatórios e backups não pertencem a esta
  pasta;
- antes de testes de importação, registrar nome, tamanho e hash da fonte.
