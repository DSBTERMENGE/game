# Dados iniciais

Esta pasta não deve conter uma cópia manual dos resultados históricos.

Os concursos serão importados pela aplicação Python a partir de uma fonte
validada. O importador deverá conferir os campos e evitar duplicações pelo
`numero_concurso`.

Seeds futuros deverão conter somente dados pequenos, controlados e necessários
ao funcionamento da aplicação.
